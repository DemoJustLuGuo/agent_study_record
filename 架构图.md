## 项目架构示意（文件树）

```text
agent_study_record/
|-- app/
|   `-- main.py                       # Flask API: /api/chat /api/rag/query /api/knowledge/*
|-- agent/
|   |-- react_agent.py                # create_agent 编排、路由与流式输出
|   |-- middleware.py                 # monitor_tool/log_before_model/log_after_model/report_prompt_switch
|   `-- tools/
|       |-- registry.py               # 统一工具注册（register_tools/get_registered_tool_map）
|       |-- agent_tools.py            # 兼容导出层（保留历史导入路径）
|       `-- modules/                  # 工具实现拆分目录（rag/web/compute/external/memory/context）
|-- rag/
|   |-- rag_service.py                # RAG 检索+生成（answer_with_references）
|   |-- vector_store.py               # 文档切分、向量入库、manifest/snapshot/rollback
|   |-- knowledge_base.py             # 知识上传与生命周期接口封装
|   `-- memory_service.py             # 长期记忆写入/检索（复用 Chroma）
|-- model/
|   `-- factory.py                    # chat model 与 embedding model 工厂
|-- config/
|   |-- rag.yml                       # 外部业务数据配置
|   |-- chroma.yml                    # 向量检索参数
|   |-- prompts.yml                   # 提示词路径映射
|   `-- agent.yml                     # 模型与推理配置
|-- prompts/
|   |-- main_prompt.txt               # 常规模式提示词
|   |-- report_prompt.txt             # 报告模式提示词
|   `-- rag_summarize.txt             # RAG 摘要提示词
|-- electron/
|   |-- main.js                       # Electron 主进程（IPC 路由 + 后端健康检查与拉起）
|   |-- preload.js                    # contextBridge 安全桥
|   `-- renderer/                     # 桌面 UI（聊天、RAG 直答、知识库管理）
|-- data/                             # 知识源文件
|-- chroma_db/                        # Chroma 持久化目录
`-- logs/                             # 运行与追踪日志
```

### 核心调用链

1. electron/renderer/app.js -> electron/preload.js -> electron/main.js
2. electron/main.js -> app/main.py（/api/chat 或 /api/rag/query）
3. /api/chat -> agent/react_agent.py -> agent/middleware.py
4. Agent 工具调用 -> agent/tools/registry.py -> agent/tools/modules/*.py -> rag/rag_service.py 或 rag/memory_service.py -> rag/vector_store.py -> chroma_db/
5. /api/knowledge/* -> rag/knowledge_base.py -> rag/vector_store.py

### 模块说明（简明）

- Electron 层（renderer/preload/main）：负责桌面 UI、IPC 桥接、后端探活与自动拉起。
- Flask API（app/main.py）：对外统一提供聊天、在线 RAG、知识上传与生命周期接口。
- Agent 层（agent/react_agent.py + agent/middleware.py）：负责规划、工具编排、监控日志、提示词切换。
- 工具层（agent/tools/registry.py + agent/tools/modules/*.py）：负责工具统一注册与分层实现（agent/tools/agent_tools.py 仅保留兼容导出）。
- RAG/Memory 层（rag/*.py）：统一承接向量检索、知识库治理、长期记忆读写。
- 配置/模型层（config + model/factory.py）：管理模型参数、检索参数与提示词路径映射。
